# Naman Creative Advertising

**Your Trusted B2B Plastic Products Partner**

A responsive business website developed for **Naman Creative Advertising**, a business that connects customers with high-quality plastic manufacturing products for wholesale and bulk orders.

This project is currently under active development and serves as a digital platform where customers can browse products, learn about the business, and request quotations through WhatsApp or phone.

## Features

- Responsive and mobile-friendly design
- Modern landing page
- Product categories
- Featured products section
- About Us section
- Contact section
- WhatsApp and phone integration
- Quotation call-to-action
- Clean and professional UI

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Git
- GitHub

## Future Enhancements
